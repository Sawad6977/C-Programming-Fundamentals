# 🏦 Bank Account Management System in C

A robust **Bank Account Management System** developed in **C programming language** with **file handling** support. This project provides essential banking functionalities such as account creation, deposits, withdrawals, balance inquiries, and account management through a simple menu-driven interface.

## ✨ Features

* Create New Bank Account
* Deposit Money
* Withdraw Money
* Check Account Balance
* View All Bank Accounts
* Persistent Data Storage using File Handling
* Menu-Driven User Interface

## 🛠️ Technologies Used

* **C Programming Language**
* **File Handling**
* **Structures**
* **Functions**
* **Arrays**

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-repository-link>
```

### 2. Open the Project

Open the project folder in **VS Code**, **CodeBlocks**, or any C IDE.

### 3. Compile the Code

Using GCC compiler:

```bash
gcc main.c -o bank
```

### 4. Run the Program

```bash
./bank
```

## 📋 Menu Options

## 💾 File Storage

The project stores account data in:

```plaintext

```

This ensures data is saved and loaded even after closing the program.
